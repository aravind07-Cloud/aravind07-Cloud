## Things I care about

- **Infrastructure as code, all of it** — if it isn't in a template, it doesn't exist. 14-stack environments stood up and torn down with one script.
- **Resilience you can prove** — chaos drills with AWS Fault Injection Simulator, forced Multi-AZ database failovers, load tests that push autoscaling to its ceiling. Zero-downtime is a test result, not a slide.
- **Security by default** — KMS everywhere, secrets that are generated instead of typed, least-privilege IAM, enforced MFA, WAF in front of everything.
- **Cost discipline** — tagged resources, budget alarms, weekly cost reports. Cloud bills should never be a surprise.
